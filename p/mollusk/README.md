## Project Description
A cryptology puzzle. The game is centered around a bookcase and its trinkets. The player must find and decipher five passwords which will decipher one final password. Since this is mostly a visual project, players must use their critical thinking in their exploration of multiple disciplines. Furthermore, users must justify their guesses. Verification: players must type their guess *and* choose the correct word from a word map that explains the source of their answer. For example, [bubble] with the source [hourglass] from the word map is a potential solution. Features include a user notepad.
